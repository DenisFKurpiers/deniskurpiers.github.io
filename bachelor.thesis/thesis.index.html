The Brown/Washington Model of Anatomy

The Brown/Washington model of anatomy as formalized in [2] is a quadruple \((\Omega, \mathcal{H}, \mathcal{I}, \mathcal{P})\), where the background space \(\Omega\) is defined as the union \(\Omega = \bigcup_{\alpha} M_{\alpha}\), where \(M_{\alpha}\) are 0, 1, 2, 3-dimensional manifolds, and \(\alpha \in I\), where \(I\) is the set of indexes. \(\mathcal{H}\) is the set of diffeomorphic transformations on the background space, \(\mathcal{H}: \Omega \leftrightarrow \Omega\). \(\mathcal{I}\) is the space of medical imagery and \(\mathcal{P}\) the set of probability measures on \(\mathcal{H}\).

If \(\mathcal{H}\) is constructed to be rich enough, we can operate under the basic assumption that there is essentially only one deformable template (\(I_{temp}\)), i.e., one anatomical ensemble \((\Omega, \mathcal{H}, \mathcal{I}, \mathcal{P})\), which forms a homogeneous space, or what is called homogeneous anatomy.

The basic property of this homogeneous anatomy is that it can be completely generated from one of its elements, defined as \(\mathcal{I} = \mathcal{H}I_{temp}\), \(I_{temp} \in \mathcal{I}\). In the homogeneous anatomy setting, all elements \(I \in \mathcal{I}\) are essentially the same modulo a diffeomorphism in \(\mathcal{H}\).

Note: This simply means that there is a single, ideal anatomy, and all normal biological variations can be generated by transforming this one template.

More generally, as for the disease state, an area that has received less attention than the study of normal anatomy, we shall require a family of templates \(\bigcup_{\alpha} I^{\alpha}_{temp}\) with perhaps varying dimensional transformation classes. The complete anatomy is built from collections of homogeneous spaces \(\mathcal{I}_{total} = \bigcup_{\alpha}(\mathcal{I}^{\alpha}, \mathcal{H}^{\alpha})\).

Within this framework, [2] argues that there are three usecases:

  1. Computation of large deformation maps: Computing diffeomorphisms \(\varphi\) from one anatomy \(I_n\) to \(I_m\), where \(I_n, I_m \in \mathcal{I}\).
  2. Computation of empirical probability laws: Calculating the probability laws \(P \in \mathcal{P}\) on \(\mathcal{H}\), which represent anatomical variation.
  3. Computational inference on population and disease testing and classification: Performing Bayesian classification and testing for anomaly, given prior probability measures.

Large Deformation Maps

Large deformation mapping, [2] argues, is the generation of bijective maps between templates and targets. These maps are preferably of high dimension, to accommodate the very finest details in variation in individual anatomy.

These large deformation diffeomorphisms are constructed as the solution of an ordinary differential equation corresponding to the transport equation in mechanics. The deformation thus corresponds to flows.

The purpose in constructing invertible maps is that they can be used to study the features of the target anatomies.

Transport Equation

As I dig into the actual computation of these mappings, I inevitably run into the Transport Equation. From my understanding, the transport equation models how a scalar quantity moves through space over time at a constant velocity \(\alpha\).

In a 1D continuous space \(\mathbb{R}\), it looks a lot like this: $$ \frac{\partial u(\vec{x}, t)}{\partial t} + \alpha \frac{\partial u(\vec{x}, t)}{\partial x} = 0 $$

By rearranging this, we can see that the rate of change over time corresponds to the flow across space: \(\frac{\partial u}{\partial t} = -\alpha \frac{\partial u}{\partial x}\). Analytically, the exact solution is just a translation of the initial state: \(u(x, t) = u_{ini}(x - \alpha t)\).

The Method of Lines

Instead of tackling space and time all at once, I use the Method of Lines. This strategy slices physical space into a rigid matrix of discrete grid points, but leaves time continuous.

By doing this, the PDE is fractured into ODEs. I essentially isolate the spatial derivative, calculating the momentary flow at every single grid coordinate \(u_{i, j}\) using approximations like finite differences, Lax-Friedrichs, or Upwind schemes. This leaves me with an ODE for every pixel: \(\frac{du_i}{dt} = f(t, u)\).

    • FDM (Central Difference): Looks at the neighbors on both sides to find the slope. Simple, but physically blind and highly prone to numerical instability.
      fu[i] = -velocity * (u[i + 1] - u[i - 1]) / (2 * self.h)

    • Lax-Friedrichs: Takes the Central Difference but adds an artificial diffusion term. When time-stepped later, this stabilizes the simulation and prevents the math from blowing up into chaotic oscillations.
      fu[i] = -velocity * (u[i + 1] - u[i - 1]) / (2 * self.h) + (u[i + 1] - 2 * u[i] + u[i - 1]) / (2 * tau)

    • Upwind: Dynamically checks the direction of the velocity (the "wind") and calculates the slope using only the pixel behind the current flow, preventing information from traveling backward against the current.
      If velocity > 0:
      fu[i] = -velocity * (u[i] - u[i - 1]) / self.h
      Else:
      fu[i] = -velocity * (u[i + 1] - u[i]) / self.h
